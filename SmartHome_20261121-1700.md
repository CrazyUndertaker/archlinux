# Linux Server

It is possible to use any Linux distribution. Here is Arch Linux selected an lightweight and flexible Linux distribution with a rolling release design.

## Arch Linux

### Install on a computer

Download installation image for Arch Linux from [https://archlinux.org/download/](https://archlinux.org/download/) (~1.2 GB 2026-11-11) and write it with Rufus ([https://rufus.ie/en/](https://rufus.ie/en/)) as a lightweight Windows utility for writing ISO images to USB drives to an USB stick.

Boot the computer via the USB stick.

Check available keymaps:

```
localectl list-keymaps | grep latin
```

Load a german keyboard layout:

```
loadkeys de-latin1
```

Set the font to a „good“ size:

```
setfont ter-132b
```

Easiest way conect computer with LAN via Ethernet or use iwctl to connect to WLAN/WiFi.

```
ip link

ip addr
```

Test the connection to the internet with the command:

```
ping -c 5 ping.archlinux.org
```

Check if date and time are synced

```
timedatectl
```

Check installed hard disk drives

```
fdisk -l
```

Example:

/dev/sda1	boot: yes	size: 484mb	id: c	type: W95 FAT32 (LBA)  
/dev/sda2	boot: no	size: 36.8gb	id: 83	type: Linux  
/dev/sda3	boot: no	size: 201.2gb	id: 83	type: Linux

#### setup for UEFI

change partition on disk

1. UEFI for boot

2. Swap for linux ~32GB

3 Root filesystem / all the rest of the disk

Use here a curses supporting fdisk derivat. First remove all existing partions from sda, then create a new 1Gb partion in EFI format (Type ef, primary, boot). After that creating a 32Gb Linux swap partition (Type 82, primary) and at least create a Linux with all the rest of the sda disk (Type 83, primary). At the end the data is writen to the disk and the utility could be quit.

```
cfdisk /dev/sda
```

Check the disk partions again with:

```
fdisk -l
```

/dev/sda1	boot: yes	size: 954M	id: ef	type: EFI (FAT-12/16/32)  
/dev/sda2	boot: no	size: 29.8G	id: 82	type: Linux swap / Solaris  
/dev/sda3	boot: no	size: 207.7G	id: 83	type: Linux

Format the EFI partion (sda1):

```
mkfs.fat -F 32 /dev/sda1
```

Format the swap partion (sda2):

```
mkswap -f /dev/sda2
```

Format the root (/) partion (sda3):

```
mkfs.ext4 -F /dev/sda3
```

Mount now the partions:

```
mount /dev/sda3 /mnt

mount --mkdir /dev/sda1 /mnt/boot

swapon /dev/sda2
```

#### Install and configure the system

Install the linux packages on the system

```
pacstrap -K /mnt base base-devel linux linux-firmware vim nano less
```

Create fstab file:

```
genfstab -U /mnt >> /mnt/etc/fstab
```

Now chroot to new install system:

```
arch-chroot -S /mnt
```

set the local timezone file:

```
ln -s /usr/share/zoneinfo/Europe/Berlin /etc/localtime
```

create a drift file for the hardware clock:

```
hwclock --systohc
```

generate local files:

```
locale-gen
```

set the system language (e.g. english):

```
echo "LANG=en_US.UTF-8" >> /etc/locale.conf
```

set the keyboard layout (e.g. german):

```
echo "KEYMAP=de-latin1" >> /etc/vconsole.conf
```

set the hostname of this computer:

```
echo "docker" >> /etc/hostname
```

create possible RAMFS with cpio support:

```
mkinitcpio -P
```

set root password and store it in bitwarden:

```
passwd
```

#### Install and configure bootloader for BIOS

install grub

```
pacman -S --noconfirm grub os-prober
```

Install grub in MBR of the disk (not in a partition)

```
~~grub-install --target=i386-pc /dev/sda~~

grub-install /dev/sda
```

Configure grub automaticly

```
grub-mkconfig -o /boot/grub/grub.cfg
```

End the chroot environment

```
exit
```

Disable swap

```
swapoff /dev/sda2
```

Unmount new Arch Linux installation partition

```
umount /dev/sda1
```

Reboot the system to new installed system

```
shutdown -r now
```


login to new system use credetials for root that was set during installation procedure

Start network (ethernet (LAN) only here) and also DNS resolutions service (resolved)

```
systemctl enable --now systemd-networkd.service

ln -s /usr/lib/systemd/network/89-ethernet.network.example \
  /etc/systemd/network/89-ethernet.network

systemctl enable --now systemd-resolved.service
```

login to new system and check if it is working with a ping 

```
ping -c 5 ping.archlinux.org
```

Install ssh & sshd

```
pacman -S --noconfirm openssh
```

start sshd server (sshd)

```
systemctl enable --now sshd.service
```

Add local user crazy and set new password for user

```
useradd -m -G wheel -s /bin/bash crazy

passwd crazy
```

Enable sudo without password for group wheel users

```
echo "%wheel ALL=(ALL:ALL) NOPASSWD: ALL" >> /etc/sudoers
```

Logout and login as new user then check sudo

```
cat /etc/shadow

sudo cat /etc/shadow
```

Install git

```
sudo pacman -S --noconfirm git

git config --global user.email "crazyundertaker@gmx.de"

git config --global user.name  "CrazyUndertaker"
```

Install python

```
sudo pacman -S --noconfirm python
```

Disable root login

```
cat /etc/passwd | grep root

sudo usermod -s /usr/bin/nologin root

cat /etc/passwd | grep root
```

System is installed and ready to use!!!

### Webadmin Interface Cockpit

Via this interface it is possible to do simple adminitration of the Linux OS.

Install the package with:

```
sudo pacman -S --noconfirm cockpit pcp cockpit-pcp
```

Enable/start the package with:

```
sudo systemctl enable --now cockpit.socket
```

Check that it is running:

```
sudo ss -tulnp | grep 9090
```

Add local admin user for cockpit interface OR use existing user with admin rights (sudo):

```
sudo useradd mycockpit -m -G wheel -s /bin/bash

passwd mycockpit
```

For metric history install pcp:

```
sudo pacman -S --noconfirm pcp cockpit-pcp
```

Enable/start the package with:

```
sudo systemctl enable --now pmcd.service pmlogger.service
```

Connect to server via webbrowser with this link:

```
https://<server-ip>:9090
```

In the upper right corner change language after login and enable admin rights.





# Docker

### Install docker package

```
sudo pacman -S --noconfirm docker docker-compose
```

Enable and start docker service

```
sudo systemctl enable --now docker.service
```

Add local user to docker group

```
sudo usermod -a -G docker crazy
```

Login out and in again with local user to activate new group!

Check docker access

```
docker info
```

Check to be able to run a container

```
docker run -it --rm archlinux bash -c "echo Hello_World!"
```

Create a local user for file ownership


Create a directory for central docker containers

```
sudo useradd mydocker -m -G docker -s /bin/bash

sudo passwd mydocker

sudo mkdir -p /opt/my-docker-containers

sudo chown mydocker:docker /opt/my-docker-containers

ln -s /opt/my-docker-containers ~crazy
```
